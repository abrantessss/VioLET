5. PI CONSOLE — controller run (after hardware/Offboard validation)
Stop any previous pf_los4 instance before opening the UART.
Gains, mass, thrust mapping and limits remain the existing simulation defaults.

./build/pf_los4 serial:///dev/ttyAMA0:115200 10 udp://192.168.1.94:14540 --controller-enabled true --test-gamma false --offline false --rc-channel 7 --kill-channel 6 --kill-active-high true --return-mode manual

RC/PX4 arms and takes off (arm switch channel 5).
Channel 6 HIGH kills/inhibits control; the script never clears kill.
Channel 7 low/mid: Manual. While airborne with adequate speed, wait in Manual
for >=1.2 seconds to establish the required Offboard preparation stream.
Channel 7 HIGH and actual PX4 Offboard: LOS4 active, gamma advances.
Switch low/mid: active controller stops; RC selects Manual.
Fault or stale input: stop setpoints, request Manual, latch until Manual cycle.
Link/process loss recovery still relies on PX4 configured failsafes.
The script NEVER requests arming, takeoff or entry into Offboard.

6. SEPARATE PI CONSOLE — camera

rpicam-vid -t 0 -n --codec h264 --inline --width 640 --height 480 --framerate 15 --bitrate 1000000 --intra 15 --listen -o tcp://0.0.0.0:8888

RViz shows actual mode, armed and kill status above the vehicle.
Named actuators: motor MAIN8, elevator MAIN4, rudder MAIN3, right aileron MAIN2,
left aileron MAIN1. Plot scaling defaults: PWM1000=-1, PWM1500=0, PWM2000=1.
